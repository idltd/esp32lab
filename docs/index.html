See it in action

A C3 SuperMini, a mini breadboard, a few jumper wires and a sensor. That's the whole lab.

1. Pick a board

The firmware runs on either of these. Start with the C3 if you're unsure — it's tiny, cheap and has USB-C.

Recommended

ESP32-C3 SuperMini

Thumbnail-sized RISC-V board with WiFi and USB-C. Usually sold in multi-packs — handy for a class or a spare.
